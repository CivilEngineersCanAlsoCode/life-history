# BRD 12.17.5 — Framework Data to LUMI

## Parent Requirement
12.17 — Data Considerations

## Status
Not Built

## Requirement
All data related to CRR framework (elements, weightings) and all updates must be available to LUMI. Include all historical data.

## Key Details
- All CRR framework data available to LUMI:
  - Risk Elements
  - Weightings
  - All framework updates and changes
- Must include all historical data
- Enables framework analysis and audit outside GCIP

## Coaching Notes
- Framework data = Categories, Elements, Weightings, Rules, FA configurations, Asset Manager configs
- Version history (12.7.2) must be included — each CRR version uplift creates a new snapshot
- Maps to R16 (Scoring Matrix Report) and R13 (FA/Lists changes) for LUMI consumption
- Asset versioning (new in POA) provides richer historical framework data than Cadence
