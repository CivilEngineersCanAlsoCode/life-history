# BRD 12.17.2 — Current Data Usage

## Parent Requirement
12.17 — Data Considerations

## Status
Not Built

## Requirement
Target state must use most current data available in AMEX ecosystem for CRR calculations.

## Key Details
- CRR calculations must leverage the most current data available
- Data sourced from across the AMEX ecosystem
- Eliminates reliance on stale or outdated data
- Ensures risk ratings reflect the latest customer information

## Coaching Notes
- Connected to rescoring frequency (12.16): daily delta for profile changes, monthly for transactional data
- Time-based flag optimization: skip re-running rules for data that only changes monthly
- Stale data is tracked via CRR Report R11 (data quality) and 12.18.1 Report 4 (stale data usage)
