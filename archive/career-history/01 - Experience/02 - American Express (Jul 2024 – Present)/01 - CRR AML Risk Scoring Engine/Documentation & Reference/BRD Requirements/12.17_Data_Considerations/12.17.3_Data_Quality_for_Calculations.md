# BRD 12.17.3 — Data Quality for Calculations

## Parent Requirement
12.17 — Data Considerations

## Status
Not Built

## Requirement
Data must be available to support risk element rating calculations with high integrity.

## Key Details
- Data supporting risk element rating calculations must be high integrity
- Data quality standards must be defined and enforced
- Ensures accurate and reliable CRR scoring outcomes

## Coaching Notes
- Maps to CRR Report **R11**: Data quality report (fill rates, data freshness)
- Data quality is a pre-requisite for 12.19 (AI/ML) — must be solved before ML-based scoring
- 48 metrics defined across CRR and DAM ownership — many relate to data quality dimensions
