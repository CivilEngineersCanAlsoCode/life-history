# BRD 12.14.5 — Customization Request UI

## Parent Requirement
12.14 — User Interface / Experience

## Status
Yes

## Requirement
Enable users to place customization requests via UI.

## Key Details
- Users can submit customization requests directly through the UI
- Streamlines the request process for framework changes

## Coaching Notes
- Currently done via SharePoint "CRR Customization Form" at teams/GFCC-RMO (~10 requests/month, 49 completed historically)
- POA target: digitize this into the CRR platform with structured workflow, form validation, auto-capture
- Maps directly to 12.2 (Change Request) — this sub-req is the UI entry point

## Cross-Reference
See BRD 12.2 — Change Request for the full change request workflow.
