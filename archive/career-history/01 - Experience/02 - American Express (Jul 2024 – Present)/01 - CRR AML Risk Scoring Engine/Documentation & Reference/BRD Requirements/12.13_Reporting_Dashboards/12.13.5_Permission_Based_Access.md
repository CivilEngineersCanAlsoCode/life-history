# BRD 12.13.5 — Permission-Based Access

## Parent Requirement
12.13 — Reporting / Dashboards

## Status
Not Built

## Requirement
Access to reporting based on permissions.

## Key Details
- Report access controlled by user permissions
- Ensures data visibility aligns with user entitlements
- Permission model must be configurable

## Coaching Notes
- Depends on 12.21 (IAM) — same blocker as 12.2.2, 12.3.2, 12.8.3, 12.9.4
- Key user roles for reporting access: MCO, MLRO, FIU, Enterprise Compliance
- MCO/MLRO should see results without edit capability (view-only access per 12.9.4)
