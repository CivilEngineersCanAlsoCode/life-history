## Coaching Context

### Current State vs AI/ML Future:
- **Current (POA):** Rule-based scoring — deterministic, transparent, configurable via sandbox
- **Future (2027):** AI/ML-based scoring — probabilistic, requires explainability, potentially more accurate
- Current rule-based approach provides the **explainability** that regulators require — AI/ML must match or exceed this

### Pre-requisites (from other BRDs):
1. **12.17 Data Considerations** must be resolved — data quality is foundational for ML training
2. **12.15 Customer CRR View** provides factor contribution transparency — ML model must provide equivalent
3. **12.7 Audit** trail must extend to ML model decisions
4. **12.16 Rescoring** infrastructure must support ML model inference alongside rule-based scoring

### Strategic Context:
- AI/ML is a **long-term vision** (2027+), not a near-term priority
- Current focus is on completing the rule-based POA platform first
- ML would augment or replace the rules-based approach, not the sandbox/governance framework

## Interview Notes
