# 12.1.2 — Risk Elements & Weighting Structure

**Parent:** 12.1 CRR Structure and Setup
**Status:** In Development

## Requirement
- Risk Elements will be categorized within the Risk Category
- The Risk Element will have a Weighting
- The Risk Element will have rules/ruleset to set the Multiplier
- **Risk Points = Weighting × Multiplier**

## Key Concept
This is the core scoring formula. Each risk element contributes Risk Points to the overall customer score. The Weighting is a static importance factor, while the Multiplier is dynamically determined by rules.

## Production Data Insights

### Weighting Patterns (from Prod Rules Export)
- **Standard weights:** Range from 0 to ~900, assigned per risk element per market
- **Weight 0:** Element is deactivated (e.g., Repat elements in non-applicable entities)
- **Weight 4000:** Special HRO override — auto-sets customer score to 9 (High Risk)
- **ARF weights:** 3 levels — Low (~300), Medium (~600), High (~900) — cumulative impact

### Element Distribution Insights
- **116 total risk elements** across 5 categories
- Elements are **market-configurable** — same element can have different weights per market
- **Multiplier** is dynamically set by rules — two types:
  - **Value-based:** Static number (0-99, decimals allowed) set by rule creator
  - **FA-based:** Dynamic inherent risk score (1-10) pulled from Fundamental Assessment table
- **Formula confirmed:** Risk Points = Weighting × Multiplier

### Hierarchy (Confirmed from Production)
```
Framework
└── 5 Risk Categories (FIXED)
    └── 116 Risk Elements (configurable per market)
        └── Rulesets (grouping logic)
            └── 11,941 Individual Rules (operators + datapoints + values)
```

## Discovery Questions (Answered)
- **Is the hierarchy strictly 5 levels?** → YES. Framework → Category → Element → Ruleset → Rule
- **Can a Risk Element belong to multiple Categories?** → NO. Each element belongs to exactly one category.
- **What is the maximum depth of nesting required for Rulesets?** → Single level. Rules belong to rulesets, rulesets belong to elements. No deeper nesting.
