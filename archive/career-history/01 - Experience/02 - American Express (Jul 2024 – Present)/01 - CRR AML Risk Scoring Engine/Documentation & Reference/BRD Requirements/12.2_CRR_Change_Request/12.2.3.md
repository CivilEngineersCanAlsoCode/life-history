# 12.2.3 — Default User Permissions

**Parent:** 12.2 CRR Change Request
**Status:** Not Started

## Requirement
For the default setup:
- Only MLRO teams should be able to submit a request
- Only the core CRR team should be able to review and disposition the request

## Current Process (SharePoint Baseline)
- **Today:** Informally enforced — MCOs/MLROs submit forms, GFCC-RMO team (CRR team) reviews and implements
- **No system enforcement:** Any SharePoint user could technically submit or modify entries
- **Review tracking:** "Sign-off Status", "GFCC-RMO Notes" columns updated manually by CRR team

## What 12.2.3 Aims to Digitize
Default RBAC configuration:
| Role | Submit | Review | Disposition |
|------|--------|--------|-------------|
| MLRO/MCO Teams | Yes | No | No |
| Core CRR Team | No | Yes | Yes |

- System-enforced permissions (not just process-enforced)
- Configurable — default setup can be adjusted if organizational structure changes
- Aligns with broader CRR user types: MCO = view-only + submit change requests; CRR Business User = review + implement changes
