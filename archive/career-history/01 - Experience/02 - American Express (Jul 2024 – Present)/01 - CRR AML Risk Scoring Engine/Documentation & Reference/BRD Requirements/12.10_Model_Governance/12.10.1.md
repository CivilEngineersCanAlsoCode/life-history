# 12.10.1 — Production Promotion Trigger

**Parent:** 12.10 Model Governance
**Status:** Yes

## Requirement
Once sandbox simulation validated, system must allow user (permission-based) to trigger/move change to production.

## Confirmed Details (from Coaching)
- After simulation results are reviewed and user is satisfied, they can trigger production promotion
- Permission-based: only authorized users can initiate the promotion
- Trigger shows all changes that will be promoted (rules + assets + FA)
- Config is frozen after simulation submit — no further edits until promotion or rollback

## Interview Notes
- Built and functional in current system
- Part of sandbox lifecycle: Simulation Complete → Review Results → Trigger Promotion → 2-Step Approval → Production
