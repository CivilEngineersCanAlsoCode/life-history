# BRD 12.12.3 — Real-Time Onboarding Integration

## Parent Requirement
12.12 — Integration with AML Ecosystem

## Status
Not Built

## Requirement
System must support real-time CRR at onboarding (new customers and new products for existing customers). Use all available info. Calculate using entire CRR framework. SLA: sub-2 seconds.

## Key Details
- Real-time scoring at customer onboarding
- Covers new customers and new products for existing customers
- Must utilize all available information at time of onboarding
- Calculation must use entire CRR framework
- SLA requirement: sub-2 seconds response time

## Coaching Notes
- Cadence was batch-only — real-time scoring at onboarding is a **new POA capability**
- Must run the entire CRR framework (all rules, weights, FA, assets) in sub-2 seconds
- Connects to 12.18.1 Report 5 (Real-Time Onboarding Performance) for SLA monitoring
- Architecture challenge: current scoring is via PubSub to Rule Execution Team (async) — real-time requires synchronous scoring path

## Critical Gap
**KEY: This capability does NOT exist today.** No real-time scoring API exists. Only daily batch processing at 7pm MST is currently available.
