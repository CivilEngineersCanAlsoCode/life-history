# BRD 12.16.2 — Framework Update Rescoring

## Parent Requirement
12.16 — Rescoring Capabilities

## Status
In Development

## Requirement
Rescore population when CRR framework enhancements/updates implemented (at time of implementation).

## Key Details
- Triggered by CRR framework enhancements or updates
- Rescoring occurs at the time of implementation
- Applies to the full affected customer population
- Ensures risk ratings reflect the latest framework changes immediately

## Coaching Notes
- Triggered when sandbox changes are atomically promoted to production (12.10)
- After 2-step approval → production merge → CRR version incremented → immediate rescore
- Scope: only re-run affected rules/elements, not full population (optimization)
- This is the "implementation" action in the sandbox lifecycle: Simulate → Review → Approve → Implement (rescore) → Production live
