# BRD 12.16.1 — Automated Rescoring Frequency

## Parent Requirement
12.16 — Rescoring Capabilities

## Status
In Development

## Requirement
Monthly process for transactional/time-based updates. Daily delta for customer profile updates.

## Key Details
- Monthly rescoring process for transactional and time-based updates
- Daily delta rescoring for customer profile updates
- Automated execution without manual intervention

## Coaching Notes
- **Time-based flag** on risk elements enables smart split: elements flagged as time-based only run in monthly cycle (performance optimization)
- Daily delta handles customer profile changes (new accounts, attribute updates)
- Monthly handles transactional patterns, income ratios, and other time-dependent data points
- Rule Execution Team owns the execution engine; CRR team defines what/when to run

## Critical Gap
**KEY: Currently only daily batch at 7pm MST exists.** The target state requires both monthly full rescoring and daily delta capabilities beyond the current single daily batch.
