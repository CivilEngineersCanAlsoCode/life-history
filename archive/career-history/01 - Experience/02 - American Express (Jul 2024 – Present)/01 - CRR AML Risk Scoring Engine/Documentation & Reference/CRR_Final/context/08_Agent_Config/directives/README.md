# Directives

This folder contains **Standard Operating Procedures (SOPs)** written in Markdown.

## Purpose
Directives define:
- **Goals**: What needs to be accomplished
- **Inputs**: What data/information is needed
- **Tools/Scripts**: Which execution scripts to use
- **Outputs**: Expected deliverables
- **Edge Cases**: How to handle exceptions

## How to Use
1. Create a new `.md` file for each distinct task/workflow
2. Write instructions as you would for a mid-level employee
3. Update directives as you learn new constraints or better approaches

## Example Structure
```markdown
# [Directive Name]

## Goal
[What this directive accomplishes]

## Inputs
- [Required input 1]
- [Required input 2]

## Execution
1. Run `execution/script_name.py` with parameters...
2. ...

## Outputs
- [Expected deliverable]

## Edge Cases
- If [condition], then [action]
```
