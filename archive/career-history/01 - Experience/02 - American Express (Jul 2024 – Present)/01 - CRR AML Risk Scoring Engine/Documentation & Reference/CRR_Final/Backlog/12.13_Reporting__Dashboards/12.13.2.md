# Sub-Requirement: 12.13.2

**Parent Capability:** [Reporting / Dashboards](12.13_Capability.md)

## Description
System should have the ability to generate a report with all the Fundamental Assessments / Centralized Lists / Notable Lists

- This should be available at the following levels - 
> Enterprise
> Center/Market specific 
> Product
> Legal Entity

- The user should be able to pull a as-of report for the above (e.g., system should allow the user to generate the above report at any level of granularity indicated above as of 12/31/2023). 

- The user should be able to generate a report that highlights the changes in the above list (across the various levels) between 2 user specified dates.


## Discovery Questions
- [ ] For the 'changes between 2 user specified dates' feature, what is the maximum date range allowed for performance stability?
- [ ] How should the report handle hierarchy changes (e.g., a Legal Entity moving to a different Center) during the selected date range?
- [ ] Should the 'Center/Market' specific views account for user entitlements automatically?
- [ ] Are there pre-defined schedules for generating this report (e.g., nightly batch) or is it purely on-demand?
