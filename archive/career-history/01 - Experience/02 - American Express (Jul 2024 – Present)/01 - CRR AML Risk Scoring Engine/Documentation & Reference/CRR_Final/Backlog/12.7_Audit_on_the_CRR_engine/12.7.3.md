# Sub-Requirement: 12.7.3

**Parent Capability:** [Audit on the CRR engine](12.7_Capability.md)

## Description
System must track and make available for viewing any change made to the Fundamental Assessment/Notable List/ reference data (add/modify/delete with who/when and any justification)


## Discovery Questions
- [ ] Does the log need to capture the *exact* value delta (e.g., changed 'Iran' to 'Iraq') or just that a change occurred?
- [ ] Should justification fields be mandatory for *every* field edit?

## Development Status

**Status:** Yes
**Comments:** Tracks changes pushed to Production.


## System Behavior & User Journey

**System Behavior:** This requirement is handled by the core platform architecture, utilizing the standard React-Python stack. Specific behavior details are pending granular design.
