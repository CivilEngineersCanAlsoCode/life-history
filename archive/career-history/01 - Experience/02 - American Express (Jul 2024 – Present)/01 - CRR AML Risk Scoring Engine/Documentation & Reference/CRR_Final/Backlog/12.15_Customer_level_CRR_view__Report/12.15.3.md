# Sub-Requirement: 12.15.3

**Parent Capability:** [Customer level CRR view / Report](12.15_Capability.md)

## Description
System must have the ability to generate a report (access to be based on permissions) to highlight risk rating changes to a customer (within a timeframe selected by the user) and the underlying reasons (what attribute changed for the customer/or which underlying account with before and after values/when the change was made/who made the change, system, user etc.,)


## Discovery Questions
- [ ] For 'risk rating changes', should we distinguish between 'System Calculation Change' and 'Manual Override Change'?
- [ ] How deep should the 'underlying attribute changed' logic go? (e.g. if Country Risk changed, do we show the new vs old country score?)
- [ ] What is the performance expectation for generating this history report for a high-frequency trading customer?
