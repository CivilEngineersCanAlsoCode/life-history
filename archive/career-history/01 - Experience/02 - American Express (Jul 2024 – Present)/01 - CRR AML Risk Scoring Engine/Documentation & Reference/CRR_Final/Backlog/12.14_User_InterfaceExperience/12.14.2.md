# Sub-Requirement: 12.14.2

**Parent Capability:** [User Interface/Experience](12.14_Capability.md)

## Description
System should provide the user with the ability to select a specific market and render the framework in place for that market. Product design consideration - this view should be user friendly with a consideration for being able to do a side by side / overlay such that it's easy to understand what the deviations are from the enterprise framework.


## Discovery Questions
- [ ] For the 'side by side / overlay' comparison, how should we handle complex nested differences?
- [ ] When rendering the framework for a specific market, do we need to show inherited Enterprise rules vs. Market specific overrides visually?
- [ ] What is the expected load time for rendering a full market framework view?
