# Sub-Requirement: 12.12.3

**Parent Capability:** [Integration with AML ecosystem](12.12_Capability.md)

## Description
Onboarding related requirements: If an interfacing application requires the CRR to be generated or rescored as part of their process such as at onboarding or during a client refresh/review, the system must support the same.

1. System must be able to support Real-Time risk rating at onboarding (for new customers as well as in the case of new products for existing customers), using all the information that is available in the onboarding system as well as any that is already available in the firm (for existing customers) ahead of the customer approval. 

2. The risk rating should be calculated using the entire CRR framework that is applicable with the available data

3. SLA / Performance: System must target appropriate SLAs (sub 2 seconds) in scoring the CRR real time in order to support immediate decision making.
