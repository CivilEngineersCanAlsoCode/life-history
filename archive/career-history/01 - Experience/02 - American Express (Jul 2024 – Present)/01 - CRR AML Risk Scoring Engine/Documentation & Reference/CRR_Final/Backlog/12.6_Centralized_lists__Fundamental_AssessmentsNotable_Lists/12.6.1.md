# Sub-Requirement: 12.6.1

**Parent Capability:** [Centralized lists / Fundamental Assessments/Notable Lists](12.6_Capability.md)

## Description
System must have the capability to setup/update these reference lists at the below levels:
> Enterprise
> Center/Market specific 
> Legal Entity
> Product
For reference, Enterprise level lists at this time > Acquisition Channel, Industry, Geography, Company Structure, Product

## System Behavior & User Journey

**System Behavior:** The Asset Manager acts as the CRUD interface for all Reference Data (Lists, Industry Codes, Country Scores). Data is stored in normalized relational tables. The UI provides filtering, bulk upload (Excel/CSV), and version history for these lists. Changes here propagate to the Rule Execution Engine via cache invalidation or batch updates.

**User Journey:** Navigation -> Asset Manager -> Select List (e.g., 'High Risk Geographies') -> 'Edit' or 'Upload New Version' -> Validate Entries -> Save.
