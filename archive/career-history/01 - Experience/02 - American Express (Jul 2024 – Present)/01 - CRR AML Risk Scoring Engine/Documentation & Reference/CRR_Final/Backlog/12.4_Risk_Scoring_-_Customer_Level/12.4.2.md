# Sub-Requirement: 12.4.2

**Parent Capability:** [Risk Scoring - Customer Level](12.4_Capability.md)

## Description
If any interfacing/downstream application requires account level risk rating, the system must leverage the Customer level risk rating.


## Discovery Questions
- [ ] Should downstream applications consume the score via API or a daily batch export?
- [ ] Do we need to translate the 'Risk Class' (High/Med/Low) into different codes for different downstream apps?

## Development Status

**Status:** No
**Comments:** Output to DAM for downstream consumption not built. (Target 26.3)


## System Behavior & User Journey

**System Behavior:** Data Access Manager (DAM) serves as the integration layer. It acts as the data plumbing, fetching Customer Data from upstream systems (KYC, Transaction Lakes) and pushing generated Risk Ratings to downstream consumers (EDD, Investigations). It manages data lineage and quality checks.

**User Journey:** (Backend Process) Operations teams monitor Data Ingestion Reports to ensure feed health.
