# BRD 12.17.1 — Data Mapping Resolution

## Parent Requirement
12.17 — Data Considerations

## Status
Not Built

## Requirement
Data mapping issues in current state must be resolved as part of POA solutioning.

## Key Details
- Identify all data mapping issues in current state
- Resolve mapping issues as part of Plan of Action (POA) solutioning
- Ensure data flows correctly between source and target systems

## Coaching Notes
- DAM (Data Attribute Manager) handles data ingestion and mapping
- POA expanded Asset Manager from 5 data points to ALL data points — mapping complexity increased
- Data points are pre-defined; mapping must ensure source system attributes correctly map to CRR data points
- GCP architecture: Source Systems → DAM → BigQuery → Rule Execution Team
