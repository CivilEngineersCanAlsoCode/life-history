# BRD 12.12.4 — Alert Data Integration

## Parent Requirement
12.12 — Integration with AML Ecosystem

## Status
Not Built

## Requirement
Data related to Alerts should be available to CRR scoring engine post disposition. Approach for each category (EDD, SAR filing, Negative News, Sanctions) defined separately.

## Key Details
- Alert data feeds into CRR scoring engine after disposition
- Category-specific approaches required:
  - Enhanced Due Diligence (EDD)
  - SAR filing
  - Negative News
  - Sanctions
- Each category's integration approach defined separately

## Coaching Notes
- Alert disposition data = outcomes of AML investigations that should feed back into risk scoring
- Example: if SAR filed for a customer → that information should increase their CRR
- Category-specific approaches needed because each has different data structures and timing
- Sanctions data connects to Prohibited classification (score = 10, from 12.4.5 coaching)
- EDD data could trigger Very High classification (when finalized, per 12.4.5)
