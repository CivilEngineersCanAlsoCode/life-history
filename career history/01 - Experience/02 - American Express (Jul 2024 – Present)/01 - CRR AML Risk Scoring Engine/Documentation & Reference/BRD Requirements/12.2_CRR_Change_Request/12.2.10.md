# 12.2.10 — Status Updates & Notifications

**Parent:** 12.2 CRR Change Request
**Status:** Not Started

## Requirement
The CRR team must be able to set the following statuses to the request:
- "Under Review"
- "Implemented"

A notification must be sent out to the submission team/user when this occurs.

## Current Process (SharePoint Baseline)
- **Today:** Status tracked via manual column updates in SharePoint list
- **Current statuses observed:** Various free-text entries in "Status" and "Sign-off Status" columns — not standardized
- **No automated notifications:** Submitters must manually check SharePoint for status changes
- **Gap:** No visibility for requestors on when their request moves through the pipeline

## What 12.2.10 Aims to Digitize
Request lifecycle statuses:
| Status | Set By | Notification To |
|--------|--------|----------------|
| Submitted | System (auto) | CRR Team (12.2.7) |
| Under Review | CRR Team | Submitter |
| Returned for Clarification | CRR Team (12.2.8) | Submitter |
| Withdrawn | Submitter (12.2.9) | CRR Team |
| Implemented | CRR Team | Submitter |

- Automated notification at each status transition
- Submitter dashboard showing status of all their requests
- CRR team dashboard showing pipeline of requests by status
