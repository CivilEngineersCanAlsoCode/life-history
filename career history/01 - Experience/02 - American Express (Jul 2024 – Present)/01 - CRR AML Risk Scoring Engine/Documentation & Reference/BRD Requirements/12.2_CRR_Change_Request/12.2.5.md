# 12.2.5 — Attribute Tagging & Change Description

**Parent:** 12.2 CRR Change Request
**Status:** Not Started

## Requirement
The user should be able to:
- Tag one or more attributes and indicate the change they are requesting
- Have an option to put in the request as free form text (necessary when request does not directly map to an existing risk element)

## Current Process (SharePoint Baseline)
- **Today:** Users describe changes in "Business Description" free-text field and "Modification Category" dropdown (HRO / Data Element Weighting Value / Country Risk Rating Thresholds)
- **No structured attribute tagging:** Users write in prose which elements/rules they want changed — e.g., "Change PEP Present weighting from 4000 to 100 points"
- **Supporting Documents:** Users attach regulatory translations, exam findings, etc. as separate files

## What 12.2.5 Aims to Digitize
Two input modes:
1. **Structured Attribute Tagging:**
   - User selects from the framework viewer (12.2.4) one or more risk elements/rules
   - For each tagged attribute, indicate: Add / Change / Remove
   - Describe the specific change (e.g., weight from X to Y, new rule logic, etc.)
2. **Free-Form Text:**
   - For requests that don't map to existing risk elements (e.g., "create new element for X")
   - Mandatory when no attribute can be tagged
   - Supports document attachments

## SharePoint Form Field Mapping
| SharePoint Field | Platform Feature |
|-----------------|-------------------|
| Modification Category | Attribute tag selector (structured) |
| Business Description | Change description per tagged attribute |
| Supporting Documents | Document attachment (carried forward) |
