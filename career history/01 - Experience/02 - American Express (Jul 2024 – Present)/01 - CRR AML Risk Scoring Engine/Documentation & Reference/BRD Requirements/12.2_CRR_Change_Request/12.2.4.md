# 12.2.4 — Framework Viewing Capability

**Parent:** 12.2 CRR Change Request
**Status:** Not Started

## Requirement
The entitled user should be able to access the request page and be able to select enterprise, specific market/center(s) or legal entity and view the corresponding CRR framework (all the elements/categories and weighting) and the Fundamental Assessments/Lists.

## Current Process (SharePoint Baseline)
- **Today:** Users must separately reference the CRR framework (elements, categories, weightings, FA) outside the SharePoint form — typically through production CRR UI or documentation
- **No inline visibility:** When filling the SharePoint form, users cannot see what the current configuration looks like — they describe changes in free text
- **Gap:** Requestors sometimes reference elements/weights that don't exist or use incorrect terminology because they can't see the live framework while submitting

## What 12.2.4 Aims to Digitize
- Inline framework viewer within the Change Request page
- Scope selector: Enterprise → Market/Center → Legal Entity
- View of all 5 risk categories with their elements, weightings, multiplier types
- View of Fundamental Assessments (6 FA gates) and associated lists/assets
- Read-only view (changes requested through 12.2.5/12.2.6, not directly edited here)
- Contextual: user sees current state before describing desired change

## Design Consideration
This is a powerful UX improvement over SharePoint — gives requestors full visibility of what exists today before they describe what they want changed. Reduces back-and-forth with CRR team for clarification.

## Interview Notes
- Capability NOT yet built — part of future roadmap (Target PI 26.4)
- Reuses existing CRR framework display components (already built for production view)
