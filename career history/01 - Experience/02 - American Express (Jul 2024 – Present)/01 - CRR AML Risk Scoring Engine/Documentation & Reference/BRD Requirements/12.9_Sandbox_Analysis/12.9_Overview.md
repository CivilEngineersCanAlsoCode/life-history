# 12.9 Sandbox - Analysis of Results

**BRD Ref:** 12.9
**Status:** Partially built (UI only, integration pending)
**Beads Task:** career-context-6uz

## Business Requirement
System should provide the ability for users to review results from simulation exercises for better decision making and analytics.

## Purpose
Ability to validate simulation results prior to production implementation.

## Outcome
Comprehensive view of change impact on customer population.

## Confirmed Details (from 12.3 Coaching)

### Results Dashboard:
- **Production vs Sandbox** risk distribution comparison
- Grouped by: **Center × Product × Legal Entity × Risk Score**
- Metrics per row:
  - Number of accounts
  - Number of independent hierarchies
  - Number of hierarchical accounts
  - Number of customers
  - Number of obligor IDs / legal entities
- Risk bands: Low (1-3), Medium (4-6), High (7-9), Prohibited (10)

### User Journey:
1. Simulation completes → User can view results
2. Dashboard shows Production vs Sandbox comparison
3. User evaluates if changes correctly impacted risk distribution
4. **Export** dashboard for offline analysis
5. Close dashboard → return to simulation tab
6. **Implement** if satisfied, or **Create New Version** / **Rollback** if not

### 3-Way Impact View:
Configuration switcher in simulation tab:
- Impact from **Rule changes**
- Impact from **Asset Manager changes**
- Impact from **Fundamental Assessment changes**
