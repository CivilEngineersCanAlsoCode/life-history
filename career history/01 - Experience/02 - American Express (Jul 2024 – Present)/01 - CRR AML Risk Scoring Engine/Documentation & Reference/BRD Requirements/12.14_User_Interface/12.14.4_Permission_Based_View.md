# BRD 12.14.4 — Permission-Based View

## Parent Requirement
12.14 — User Interface / Experience

## Status
Yes

## Requirement
Ability to view based on user permissions (configurable).

## Key Details
- UI views controlled by user permissions
- Permission model is configurable
- Ensures data visibility aligns with user entitlements

## Coaching Notes
- Basic role-based access functional in current system
- Fine-grained permissions (who can view vs edit vs approve) pending 12.21 (IAM)
- Key roles: MCO (Market Compliance Officer), MLRO (view-only results), FIU (investigation + override access)
