# BRD 12.14.1 — Framework Rendering

## Parent Requirement
12.14 — User Interface / Experience

## Status
Yes

## Requirement
Render current CRR framework on UI: Risk Categories, Risk Elements, Weighting, Overrides and corresponding details (incl market info).

## Key Details
- Display Risk Categories on UI
- Display Risk Elements on UI
- Display Weighting values on UI
- Display Overrides and corresponding details
- Include market-level information in rendering

## Coaching Notes
- Implemented as the **CRR tab** — production read-only view
- Hierarchy displayed: Risk Category → Risk Element (name, description, min, max, prohibited flag, time-based flag) → Rulesets → Rules → Market Settings
- Market information shown inline with enterprise defaults vs market overrides
- Configuration hierarchy: Enterprise → Market (POA terminology, replacing "Center" from POD)
