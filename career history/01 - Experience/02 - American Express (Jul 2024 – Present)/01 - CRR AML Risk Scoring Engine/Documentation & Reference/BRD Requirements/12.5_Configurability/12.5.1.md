# 12.5.1 — Advanced Rule Logic

**Parent:** 12.5 Configurability
**Status:** In Development

## Requirement
Setting and updating Rules/ruleset: In addition to the "AND" clause used to create a ruleset, the system should allow:
- **OR** logic
- **Exclude/Except ("NOT")** logic
- **Parentheses** (to allow for more complicated rulesets)

## Key Concept
This is the Advanced Rule Configurations feature — the no-code visual rule builder with AND/OR/NOT logic and drag-and-drop interface. Enables analysts to create complex, market-specific rules without engineering involvement.

## Confirmed Details (from Coaching — covered in 12.3.1)

### Two Rule-Building Modes:
| Mode | Operators | Use Case |
|------|-----------|----------|
| **Basic Mode** | AND only | Simple conjunctive conditions — most common use case |
| **Advanced Mode** | AND + OR + NOT + Parentheses | Complex nested logic for sophisticated market-specific rules |

### Rule Structure:
- Rule = Datapoint + Operator + Value
- Multiple conditions combined using AND/OR/NOT operators
- Parentheses enable grouping for complex precedence logic
- All configured through UI — no engineering involvement (no-code)

### Data Point Constraints (from 12.3.3):
- 3 ratio rule types (Income Type Ratio, Income Count Ratio, Transaction Ratio) cannot have 2 aggregation-type data points together
- UI silently prevents invalid combinations
