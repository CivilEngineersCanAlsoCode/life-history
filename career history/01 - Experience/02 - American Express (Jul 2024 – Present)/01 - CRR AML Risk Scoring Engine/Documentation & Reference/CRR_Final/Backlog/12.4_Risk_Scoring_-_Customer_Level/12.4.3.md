# Sub-Requirement: 12.4.3

**Parent Capability:** [Risk Scoring - Customer Level](12.4_Capability.md)

## Description
Users must be able to override the risk rating for a customer or a target population (from current rating to Low/Medium/High/Very High)
> System should require a justification (mandatory)
> Users should be able to directly set the target population via an excel upload of customers identified (template would be finalized as part of the PRD). 
> The ability to override would be permission based (configurable).


## Discovery Questions
- [ ] If a bulk override is done via Excel upload, how do we handle invalid Customer IDs?
- [ ] Does a manual override align expiration? (e.g. override expires in 1 year)

## Development Status

**Status:** No
**Comments:** New capability for manual risk overrides to be developed.
