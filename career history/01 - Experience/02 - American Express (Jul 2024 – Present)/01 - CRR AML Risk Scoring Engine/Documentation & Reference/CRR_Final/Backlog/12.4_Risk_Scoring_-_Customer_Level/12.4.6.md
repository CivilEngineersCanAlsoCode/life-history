# Sub-Requirement: 12.4.6

**Parent Capability:** [Risk Scoring - Customer Level](12.4_Capability.md)

## Description
System should be able to set CRR to "Prohibited" for the below scenarios (irrespective of the calculated points/class). The rationale for the override should be set by the system based on the scenario.
1. If the customer/business entity address is in a comprehensively sanctioned country (North Korea, Cuba, Iran, Syria)
2. If the business entity has a prohibited company structure
