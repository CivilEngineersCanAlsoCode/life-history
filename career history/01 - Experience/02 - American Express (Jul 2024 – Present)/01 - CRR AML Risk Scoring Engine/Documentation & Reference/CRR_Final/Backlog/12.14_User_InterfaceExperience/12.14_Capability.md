# Capability: User Interface/Experience

**BRD Ref:** 12.14

## Business Requirement
System should be able to render the CRR framework on the UI 

## Purpose
Capability to have a UI to review the framework with the ability to scan across markets

## Outcome
Enhancing the user experience to have the framework easily accessible for review and updates
