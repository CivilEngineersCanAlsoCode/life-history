# Sub-Requirement: 12.18.1

**Parent Capability:** [Performance Reporting](12.18_Capability.md)

## Description
System must be able to generate the following reports related to the performance of the system: 

1. Report detailing out any data feeds that were unable to be processed in the CRR application (incl. the feed/source, volume, reason for failure etc.,).

2. Report that details out any breaks or issues noted in the processing of the CRR data. If the underlying issue relates to data quality, then details around the same should be included including attribute, volume impacted, fill rates (and any additional ones that are identified as being useful during the PRD phase).

3. Report from a DAM perspective to highlight the data attributes that could not be ingested/processed along with corresponding reason and supporting attributes.

4. Report providing details of stale data (dated information being used in lieu of more current information that is present elsewhere but not available due to system issues) if any that has been used in the CRR scoring/rescoring.

5. Report providing performance details in relation to real time CRR calculations at onboarding (new customers as well as new products for existing customers) - response times, SLA breaches, volumes etc.

6. Report providing details related to sandbox performance - actuals vs. the defined SLAs (reference: for vendor POC, this was 10 million accounts scored in 5 hours).
