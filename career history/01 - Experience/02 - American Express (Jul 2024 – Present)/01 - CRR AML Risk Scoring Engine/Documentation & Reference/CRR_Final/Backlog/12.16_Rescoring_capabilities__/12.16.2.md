# Sub-Requirement: 12.16.2

**Parent Capability:** [Rescoring capabilities  ](12.16_Capability.md)

## Description
System must have the ability to rescore population when any enhancements or updates are made to the CRR framework (at the time of implementation of the update)


## Discovery Questions
- [ ] How do we handle 'in-flight' onboarding applications when a framework update is deployed?
- [ ] Should the system support 'parallel runs' (scoring on both old and new frameworks) for a transition period?
- [ ] Does a framework update trigger a new 'Assessment Date' for the customer profile?
