# Sub-Requirement: 12.13.3

**Parent Capability:** [Reporting / Dashboards](12.13_Capability.md)

## Description
System should have a CRR Risk Distribution dashboard - this will be housed in GCIP and will be the source of truth for all users (underlying data must be sent to LUMI for subsequent consumption by additional stakeholders). This will need to be dynamic to reflect the current risk distribution of the customer population. 

- There should ability for the user to configure the views by
> Enterprise
> Center/Market specific 
> Product
> Legal Entity

- The user should be able to pull a as-of report for the CRR distribution (e.g., system should allow the user to generate the above report at any level of granularity indicated above as of 12/31/2023). 

- The user should be able to generate a report that highlights the changes in the above distribution (across the various levels) between 2 user specified dates.
