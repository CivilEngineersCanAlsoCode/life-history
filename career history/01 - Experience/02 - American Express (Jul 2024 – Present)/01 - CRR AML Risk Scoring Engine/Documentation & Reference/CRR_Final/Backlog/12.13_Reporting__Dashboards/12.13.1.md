# Sub-Requirement: 12.13.1

**Parent Capability:** [Reporting / Dashboards](12.13_Capability.md)

## Description
System should have the ability to generate a report with all the Risk Categories/Elements/Weightings (Scoring Matrix)

- This should be available at the following levels - 
> Enterprise
> Center/Market specific 
> Product
> Legal Entity

- The user should be able to pull a as-of report for the CRR framework (e.g., system should allow the user to generate the above report at any level of granularity indicated above as of 12/31/2023). 

- The user should be able to generate a report that highlights the changes in the above framework (across the various levels) between 2 user specified dates.
